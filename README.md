# Freelancer Company website

A responsive, single-page website based on the supplied mobile design.

## Deploy on Vercel
1. Create a new GitHub repository and upload `index.html` to the repository root.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Keep the default settings and select **Deploy**.

The WhatsApp buttons already link to the channel supplied by the site owner.

## Important
The changing payout cards are explicitly labelled as DEMO. They are illustrative UI previews, not actual PhonePe receipts or payment evidence. Replace them only with genuine, permissioned and verifiable payment records. Do not publish invented UTRs or fabricated payment claims.
